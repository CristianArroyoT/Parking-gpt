Los frames de cámara se almacenan en la cola y solo se persiste el resultado OCR.
Los logs de auditoría guardan la acción, el usuario y un JSON con datos de la petición.
3. Flujo de operación (Entrada → Salida)
Entrada
Cámara RTSP detecta movimiento → envía frame a RabbitMQ.
Worker OCR recibe frame → pytesseract → devuelve matrícula.
API POST /parking/{id}/entrada recibe matrícula, busca vehículo → crea ticket con hora_entrada.
Salida
Cámara RTSP detecta vehículo con matrícula (identificada) → envía frame a RabbitMQ.
Worker OCR lee frame → devuelve matrícula.
API POST /parking/{id}/salida recibe matrícula → busca ticket activo → calcula tiempo, tarifa, actualiza hora_salida, estado cerrado.
Se genera PDF (ticket, PDF con código de barras).
Facturación
Al cerrar ticket se envía email con PDF al email del usuario (si se ha registrado).
Si el usuario tiene plan de suscripción, se aplica descuento automáticamente.
Auditoría
Todas las operaciones (entrada, salida, error, OCR fallido) se registran en tabla Auditoría.
Se loguean en Loki para métricas y alertas.
4. Seguridad y auditoría
Tema	Medidas	Herramientas

Auditoría	Registro de todas las peticiones con IP, timestamp, detalle	Tabla Auditoría + Loki
Backup	RPO 1 h, RTO 30 min (cron)	pg_dump + rsync a NAS remoto
